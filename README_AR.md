# صلح — الإصدار 1.5.0

تطبيق خدمات منزلية بالعربية والإنجليزية. يعرض طلب العميل في صفحة الفني لقبوله أو رفضه، ثم بدء التحرك ومشاركة الموقع وإكمال الخدمة. الدفع مباشرة مع الفني بعد الإنجاز. تسجيل الخروج ظاهر للفني وفي الملف الشخصي.

## تخفيف الحجم

- بناء Release لكل معمارية: arm64 للهواتف الحديثة وarm32 للأجهزة الأقدم المتوافقة.
- إزالة المكتبات غير المستخدمة: Firebase وGoogle Maps وStripe ومكتبات واجهة وحالة واتصال زائدة.
- استبعاد صور المشروع الأصلية غير المستخدمة من APK؛ صور الخدمات مرتبطة بقاعدة البيانات وتُحمّل عند الطلب، مع تحديد دقة فك الصورة ومعالجة فشل التحميل.
- فحص آلي يمنع تجاوز 50 ميبيبايت لكل ملف، وتقرير بالحجم الفعلي وبصمة SHA-256.

```sh
flutter pub get
flutter analyze --no-fatal-infos --no-fatal-warnings
flutter test --reporter expanded
flutter build apk --release --split-per-abi --target-platform android-arm64,android-arm --split-debug-info=build/symbols
```

تبقى قاعدة Supabase والحسابات وبيانات الطلبات والإشعارات محفوظة. لا تُنشر كلمات مرور حسابات التجربة في المستودع. البيانات الافتراضية والصور توضيحية وليست عروضًا أو تقييمات أو هويات فنيين حقيقية. جداول السجل المالي محفوظة دون إضافة دفعات ناجحة وهمية.

التتبع يحتاج الإنترنت وإذن الموقع؛ أبقِ شاشة تتبع الفني مفتوحة أثناء الملاحة. لا يُضمن استمرار التتبع بعد إجبار التطبيق على الإغلاق. إشعارات الدفع في الخلفية غير مهيأة، ويلزم اختبار الحركة على جهازين فعليين.

توقيع هذه النسخة التجريبية بمفتاح debug الخاص بخادم البناء. قد يلزم حذف النسخة السابقة إذا اختلف التوقيع؛ البيانات المرتبطة بالحساب تبقى في قاعدة البيانات. معرّف الحزمة ثابت للتوافق، واسم التطبيق الظاهر «صلح».
